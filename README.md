# Squeek Deep

A single-player pixel-art digging game starring a Squeekchain hamster. Dig through six underground layers, stuff your cheeks with gems, dodge cave critters, and ride the basket winch back up before your cheeks overflow.

This repo holds the original art/audio asset pack and the game design doc used to build the game.

- `DESIGN.md` - full game design, controls, layers, enemies, items, UI layout, asset usage
- `public/assets/` - all game assets, served at `./assets/` (`public/assets/manifest.json` lists every file, size, frames and usage)
- `docs/` - previews: contact sheet, v1 vs v2 comparison, animation GIFs
- `src/`, `index.html` - Vite + React + TypeScript scaffold (game to be built here)
- `tools/` - scripts used to generate/clean the pixel art

Font: Pixelify Sans (SIL Open Font License). All other art and audio were created for this project.
